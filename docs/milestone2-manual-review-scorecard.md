# Milestone 2 人工复核评分表

项目名称：语义驱动的 PPT 智能图表生成与多模态配图系统

用途：真实 PPT 样例人工版式、图表质量、配图质量和演示可用性复核

关联 WBS：`M2.3`、`M2.6`、`M2.7`、`M2.10`、`M2.12`

## 1. 评分规则

每项使用 1-5 分：

| 分数 | 含义 |
|---:|---|
| 5 | 可直接用于汇报，无明显问题 |
| 4 | 轻微问题，不影响理解 |
| 3 | 可接受，但需要人工微调 |
| 2 | 问题明显，影响阅读或展示 |
| 1 | 不可接受，需要重新生成或重做版式 |

建议通过条件：

- 单项不低于 3 分。
- 总平均分不低于 4 分。
- 不存在遮挡标题、正文核心内容、图表主体或关键图片的严重问题。

## 2. 评分维度

| 维度 | 检查问题 |
|---|---|
| 解析完整性 | 标题、正文、表格、文本型数据和页面元素是否被正确识别 |
| 图表推荐 | 推荐图表是否符合趋势、对比、构成、分布或相关性场景 |
| 图表可读性 | 标签、颜色、图例、标题和数值是否清晰 |
| 配图匹配度 | 配图是否符合主题和行业风格 |
| 配图安全性 | 配图是否避免图表、坐标轴、数据看板等错误视觉元素 |
| 版式可用性 | 图表和配图是否遮挡原始核心内容 |
| PPT 可交付性 | 增强版 PPT 是否能打开、下载、用于演示 |

## 4. 单页问题记录模板

| 样例 ID | 页码 | 问题类型 | 严重程度 | 描述 | 处理建议 | 状态 |
|---|---:|---|---|---|---|---|
|  |  | 解析 / 图表 / 配图 / 版式 / 下载 | P0 / P1 / P2 |  |  | 待处理 |

严重程度说明：

- `P0`：阻塞验收，例如 PPT 无法打开、核心内容被遮挡、流程失败。
- `P1`：明显影响展示，例如图表类型不合适、文字拥挤、配图主题偏离。
- `P2`：轻微问题，例如局部间距、颜色或标题可优化。

## 5. 复核流程

1. 从 `docs/milestone2-real-ppt-sample-register.md` 选择样例。
2. 打开对应增强版 PPT。
3. 逐页检查至少 3 页：第一页、中间页、末页。
4. 按第 2 节维度打分。
5. 如发现问题，在第 4 节记录页码和严重程度。
6. 平均分不低于 4 且无 P0 问题时，可将样例标记为人工复核通过。
